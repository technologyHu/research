# 项目类型与章节裁剪

| 类型 | 分析重点 | 通常按需裁剪 |
| --- | --- | --- |
| 库／SDK | API 契约、模块依赖、生命周期、异常与集成方式 | 独立部署、持久化存储、复杂运维 |
| 框架 | 控制流、核心引擎、状态与扩展点，宿主和应用职责 | 与核心机制无关的生态枚举 |
| 中间件／数据库 | 协议、数据流、存储、一致性、可靠性、性能与部署 | 没有证据的理论峰值推断 |
| 算法库／AI 框架 | 算法、数据结构、计算流程、复杂度、训练／推理实现 | 无关业务架构与服务部署 |
| 应用系统／SaaS 的开源实现 | 用户流程、服务边界、数据、安全、部署与运维 | 无法读取的闭源服务内部实现 |
| 工具／CLI | 输入输出、命令路径、配置、错误与集成；编译器另关注阶段和 IR | 与实际使用无关的分层与存储章节 |

项目可以兼具多种形态，使用主导视角并说明交界。选择章节的依据是研究问题，而非为了完整照抄目录。没有存储／认证等机制时说明是否不适用，不自动推断存在缺陷。
