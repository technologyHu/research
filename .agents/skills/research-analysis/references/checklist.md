# 分析判断检查清单

- 是否明确问题、时间、场景、硬约束和判断标准，区分用户条件与本次假设？
- 任务输入和贡献者观点是否有归属，是否避免把偏好或任务目标强塞成需要 URL 的证据字段？
- 贡献者声称的性能、成本或经验事实若影响结论，是否仍有证据或明确保留待核实状态？
- 是否阅读采用的报告，并能定位关键事实的版本、章节、适用条件及限制？
- 是否区分已有事实、来源推断、贡献者观点与本次推导，不捏造立场、不将转述升级为独立证据？
- 关键判断能否由实际依据、假设和推导得出，反例、替代解释及取舍是否得到处理？
- 是否分别说明证据质量、关键假设状态和条件变化的敏感性，避免没有依据的置信概率或评分？
- 本地 repo: 报告是否按要求登记和核对散列，外部原始 URL 是否按实际使用引用，正文相对链接是否有效？
- 输入条件或采用来源变化后，是否更新相应范围并复核受影响判断，保留原日期和未复核部分？
- 是否给出结论的失效／反转条件及待验证问题，不把条件性建议写成已验证的全局事实？
- 是否按论证可信度、决策相关性与稳健性评价，未被要求时不增加影响力调查？
- 是否按实际问题覆盖交付完整或部分分析，并完成公共报告校验及关联计划回写？
