# 分析判断的论证质量与决策价值

用于选择分析问题、说明优先级及复核成稿。默认评估论证可信度、决策相关性和判断稳健性，不对新分析例行调查“已有影响力”，不填写没有意义的“影响力待核实”。

## 判断标准与输入条件

先明确问题是事实解释、趋势判断还是方案取舍，采用与问题相符的标准。方案取舍须区分不可违反的硬约束与可权衡的偏好，记录优先级、阈值及其由谁提出。用户未给出且会改变结论的关键条件，先说明条件性分支或询问；一般假设可明确提出，但不能冒充用户要求。

不默认制作加权评分或捏造阈值。性能、成本、复杂度等实证维度按现有可比证据讨论；价值偏好来自任务输入，不能当作经过实验确认的客观优势。

## 默认评估

| 维度 | 核对什么 |
| --- | --- |
| 论证可信度 | 依据可追溯且适用于问题，推导完整，来源独立性和反例得到处理 |
| 决策相关性 | 是否回答实际问题，明确哪些选择或理解会因此改变，是否符合当前约束与优先级 |
| 判断稳健性 | 改变关键假设、偏好排序或来源结论后，判断是否仍成立；哪些变化会使结论反转 |

新分析的价值不由作者声望、融资、来源数量或领域热度决定。对来源对象的背景评价沿用其类型标准，只核对影响本次判断的部分。

## 置信程度的表达

置信程度针对一项具体主张及明确条件，至少解释：

- 证据质量：直接还是间接，覆盖到什么场景，有何冲突或缺口。
- 关键假设状态：已核查事实、用户给定条件还是尚待验证的假设。
- 敏感性：哪项前提、阈值或优先级变化会改变结论，反转条件是否接近当前场景。

简短判断可直接用文字解释，不强制标等级。使用“较高／中等／较低”等等级时附理由，区分“在给定条件下推荐某方案”的把握与“某性能主张为真”的把握；没有依据不填写概率或精确分数。对前者把握较高，不代表后者已经证实。

complete／partial 衡量本轮问题覆盖，与置信程度分开。给定条件下可回答的问题可以完成；未回答的核心问题仍保留缺口，不能靠降低置信描述掩盖 partial。

## 已有影响的按需回顾

只有用户要求评价分析的实际影响，或优先级确实取决于既有采用时，才调查它如何影响了决策、工程或后续研究。区分已发生采用与预期用途，记录可追溯依据；不将潜在价值写成已实现影响。

### 计划中的背景字段

- 观点归属：谁实际提供哪些观点或经验，何时、适用何种场景；未提供时不推定。
- 成果依据：采用的报告、版本／日期、关键主张、限制与实际前置依赖。
- 判断条件：硬约束、偏好排序、关键假设及其来源；仅记录与问题相关的立场、利益或资源限制。
- 决策用途：要支持的选择及接受条件，说明问题相关性；已有采用仅在需要时补记。

计划中以论证质量及决策相关性说明分析项价值，以依赖成熟度、问题重要性和验证成本解释优先级。已采用不自动证明论证可靠，尚未采用也不构成低价值。
