# 分析洞察的质量与问题价值

用于选择分析主题／问题、解释优先级和复核成稿。默认评价依据可靠性、分析与解释价值、问题相关性及洞察稳健性；实际影响按需回顾，不对新报告例行调查已有采用。

## 按问题选择标准

先明确本轮是综合认识、模式归纳、机制／争议解释、演进／机会分析，还是应用取舍。不同目标采用相应评价口径，不强求统一选型框架。

主题综合检查样本选择与主要发现；模式分析检查重复现象、反例及成立条件；机制解释检查过程证据和替代解释；趋势分析检查时间依据、覆盖范围与外推；机会分析说明证据缺口如何导出值得验证的问题。方案取舍才需要区分硬约束、偏好排序与阈值，并标明由谁提出。

## 默认评估

| 维度 | 核对什么 |
| --- | --- |
| 依据可靠性 | 报告与决定性原始证据可追溯，版本、时间和场景适用，保留来源独立性及缺口 |
| 分析与解释价值 | 是否通过对照、归纳或推导揭示有意义的联系、差异或机制，说明这些认识的意义 |
| 问题相关性 | 是否回答本轮主题／问题，哪些理解或实践可能因此改变；不强制所有报告服务即时决策 |
| 洞察稳健性 | 是否考虑反例、替代解释与样本边界，关键假设或证据变化后结论如何调整 |

已有成果的摘要与分类可以作为分析基础，但数量和篇幅本身不证明分析价值。不为追求新意编造规律，不将新框架名称、作者声望或领域热度当作贡献。证据只能支持有限认识时如实表达，单项解释有价值也不要求覆盖全部形式。

## 置信程度与边界

对重要主张说明依据是直接还是间接、覆盖哪些样本与时间、有何冲突／缺口、关键假设是否核查，以及哪些反例或条件变化可能削弱结论。不把小样本共性直接提升为普遍规律，或把相关关系写成已确认因果。

文字说明即可，不默认概率、精确评分或高／中／低等级。需要等级时附实际理由，区分对样本事实、机制解释、趋势外推和应用建议的不同把握。仅在取舍分析中讨论偏好和建议反转条件，不把它们设为所有报告的必填项。

complete／partial 衡量本轮问题覆盖，与洞察是否新颖、置信程度是否高、是否完成实验验证分别判断。重要问题未获回答时保留缺口，不靠宽泛措辞掩盖 partial。

## 实际影响的按需回顾

用户要求评价报告影响，或本轮优先级确实取决于既有采用时，再核查它对后续研究、理解或实践产生的实际作用。区分已发生影响与预期价值，未采用不自动意味着低价值。

### 计划中的背景字段

- 分析目标：主题／问题、样本与时间边界、关注点、接受条件及预期解释价值。
- 成果依据：实际采用的报告、主张、版本／日期、局限与前置依赖。
- 观点与假设：贡献者实际提供的思考及归属、本次提出的假设；不推定未提供的立场。
- 相关约束：只记录确实影响本轮分析的场景、利益关系或资源条件；取舍类再补偏好与阈值。

以问题重要性、预期分析价值、依赖成熟度和验证成本解释优先级。来源对象背景沿用原类型标准，只复核与本轮结论相关的变化，不为主题虚构统一公司或融资背景。
