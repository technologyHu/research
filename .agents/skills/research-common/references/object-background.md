# 调研对象的主体、资源与利益关系

用于主题计划的候选选择和优先级解释，也可作为报告中的对象背景。先确定每个对象的实际类型，读取下表所指类型规范，选择其背景字段，再核查相应主体与关系。本文件只维护候选线索、事实记录格式和核实方法；权威性、影响力、背景字段含义及其评估作用由类型规范定义，不在这里另设通用等级或统一权重。

## 按类型选择定义与字段

| 实际类型 | 背景侧重点 | 字段与判断的唯一类型定义 |
| --- | --- | --- |
| paper | 作者单位、研究团队、论文资助及披露关系 | [论文标准](../../research-paper/references/selection-criteria.md#计划中的背景字段) |
| open-source | 发起／维护主体、维护者、项目支持、治理与下游 | [开源项目标准](../../research-open-source/references/selection-criteria.md#计划中的背景字段) |
| product | 运营公司、核心团队、适用的融资／母公司支持及客户关系 | [产品标准](../../research-product/references/selection-criteria.md#计划中的背景字段) |
| benchmark | 提出／发布／治理机构、数据与资金支持、参评及判分关系 | [评测标准](../../research-benchmark/references/selection-criteria.md#计划中的背景字段) |
| analysis | 分析目标、已有成果依据、样本边界与可选观点归属 | [分析洞察标准](analysis-criteria.md#计划中的背景字段) |

同一任务涉及异类对象时分对象记录。是否存在公司或投资安排按实际主体判断；不能因为分析使用跨类型成果，或任务表有资金列，就将所有对象按公司或产品调查。双重身份需要分别说明，例如开源项目的维护公司融资与该项目自身的采用数据分别记录。

先完成工作性质与类型路由，再按本轮问题核查相关背景。analysis 以成果依据、分析与解释目标、样本边界及实际观点归属为重点；来源对象已有背景仍适用时沿用原依据和日期，仅在机构、资源或利益关系实质影响当前判断时补查，不对每份输入重做一轮背景调查。

## 可供类型规范选用的背景线索

下表是检查遗漏的线索目录，不是每个调研项必须填写的通用表单。只把类型规范中适用且与本次问题相关的内容写入计划／报告；未使用的维度可省略，不为每项批量补“不适用”。

| 维度 | 需要辨明的事实 | 对评估的作用 |
| --- | --- | --- |
| 来源与归属 | 原始提出者、论文作者单位、实验室、公司、基金会、标准组织；发起、开发、维护、运营、发布、所有权及上游关系 | 判断专业积累、原始贡献、参考地位及责任边界 |
| 核心团队 | 创始人、负责人、关键研究者／维护者及其公开相关经历、代表工作、此前交付记录和职责 | 解释相关领域经验、技术延续性和关键人员依赖 |
| 资金与资源 | 机构内设团队、公共研究经费、商业收入、自筹、股权投资、研究资助、商业赞助、算力／数据／基础设施支持 | 判断已有投入、可核实的资源条件、持续维护能力及资源依赖 |
| 控制与治理 | 母子公司、收购、持股／控制关系、董事／治理席位、基金会托管、IP 归属、许可证及决策机制 | 判断技术方向、开放程度、决策独立性及持续性风险 |
| 合作与生态 | 联合研发、学术合作、标准制定角色、平台集成、渠道伙伴、云／硬件／模型提供方和下游项目 | 判断传播渠道、关键依赖、技术角色及可扩展生态 |
| 客户与采用 | 独立用户／组织、科研团队、试点／生产部署、真实使用与付费情况、采用版本和场景 | 支持实际影响力判断，区别宣传触达和持续使用 |
| 技术与交付积累 | 可核查的论文／实现／专利相关主张、独立验证、发布历史、维护响应和实际交付 | 支持对象类型对应的权威性及成熟度，专利数量不直接证明创新性 |
| 认可与制度地位 | 正式发表／评审、标准组织职责、参考实现、行业评选或认证的具体授予主体、范围与日期 | 解释相关领域认可，区分技术认可与付费推广或范围不符的资质 |
| 利益关系与争议 | 研究资助、股权关系、同团队复现、投资方客户、评测主办／参评关系、已核实争议与反证 | 判断来源独立性、结论适用范围和需要优先核查的风险 |

只收集与研究相关的公开职业背景和机构事实，不扩展到无关个人资料。不是每项都要填满全部维度：企业内部项目应查支持和归属，独立个人项目可能是自筹，论文关注作者单位与资助，尚无商业实体的技术方向不虚构公司或投资人。

## 投资、资助与商业关系的记录口径

本节仅在所选类型及实际对象存在相关关系时使用，不要求论文、评测或技术方向都有融资轮次、估值或股东。

- 融资记录写清被投主体、公告／完成日期、轮次、金额与币种、领投／跟投及相关战略投资角色；估值、持股和控制关系只在公开且相关时记录。单轮、累计、估值分别标识，未披露不自行相加、估算或转换为现金余额／研发投入／资金续航。
- 区分已宣布和已完成交易、投资意向与实际投资；新闻日期不代替事件日期，历史投资人不直接写成当前股东。收购、母公司支持、孵化／加速器参与、研究经费、赞助和商业合同分别记录，不统称融资。
- 写明支持方式与对象：钱、算力、数据、人员或渠道支持的是公司、实验室、项目还是具体论文。未公开的安排记未披露；没有查到记待核实，不写“无投资／无资助”。对象确无适用主体时记不适用并说明原因。
- 投资机构或资助方的相关行业经验、合作资源和战略协同可以支持潜力及资源判断，但须有具体事实。融资规模、知名投资人、知名母公司不直接证明技术领先、独立采用、盈利或长期可持续。
- 投资、赞助与合作关系不当然损害成果；也不能将同一利益网络里的宣传、客户案例、引用或复现重复计作独立背书。保留角色和限制，优先核查与核心问题有关的主张。

## 核实与使用

来源优先查看论文署名／致谢、项目治理及仓库说明、机构／公司正式公告、适用的公开登记或监管披露、投资方公告、合作方或客户的一手说明，再用独立资料交叉核对。公司官网、投资方公告属于相关方陈述，标明身份；媒体转载不增加独立性。名称相似、logo 出现、任职经历或互相链接不能单独证明投资、归属、合作或客户关系。

每条重要背景记录主体、关系类型、作用对象、适用时间、来源、核实日期，以及“已核实／仅相关方自述／待核实／未披露／不适用”。“已核实投资公告”只证明该公告及其明确内容，不表示已经独立确认未披露条款。存在冲突时保留各方说法，按 [证据规范](evidence-policy.md) 处理；不要为了丰富背景推断隐含股权或利益输送。

实际填写某个对象时，对任职、投资、收购、合作与采用等变化信息核对当时来源；沿用旧资料保留原日期。需要抓取文章时沿用现有文章流程，所有中间材料仍按交付规范进入对应 .tmp；计划只保留简明背景、来源链接及对判断的影响。

计划中的结论分四层写：背景事实、它说明的专业积累／资源条件、对权威性或影响力的实际支持及局限、对优先级的具体影响。背景强但证据弱可优先验证，背景普通但直接解决核心问题也可优先；资源潜力与已经实现的技术／市场影响分别表述。当前计划保留主体关系、来源和实际核实日期，重大归属或资金变化时复核相关判断，并在变更记录中说明原判断、变化及影响。
