# 评测体系报告结构

评测结果的解释建立在协议和条件上，不能只列榜单。

| 默认字段 id | 章节／问题 |
| --- | --- |
| identity | 名称、维护方、版本、日期、论文、代码、数据与许可 |
| objective | 测什么能力、目标使用场景及不覆盖的能力 |
| dataset | 样本来源、规模、划分、构造、去重、任务难度与污染风险 |
| protocol | 模型接口、工具、预算、采样、重试、环境、停止条件与评测流程 |
| metrics | 指标定义、分母、聚合方式、判分器、部分得分与失败处理 |
| results | 基线与榜单、日期、版本、方差／置信区间及成本条件 |
| validity | 可比性、代表性、判分偏差、数据泄漏、公平性和可复现性 |
| assessment | 适合回答的问题、适用边界及采用建议 |

对比多个评测时先建立“能力—任务—指标—协议”对应关系。比较模型成绩前核对运行框架和预算；不同框架、不同 test split 下的分数分开陈述。
