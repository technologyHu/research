# 论文报告结构

标题下使用工具生成的简短说明，正文按下列结构组织。见 [报告开头](../../research-common/references/writing-policy.md#报告开头)。

根据目标与深度合并或展开下列部分。survey 论文改用 [survey 阅读规范](survey.md) 中的字段，仍归 paper；不强填原创算法、实验或复现章节。先固定论文版本并定位与问题相关的方法、实验及必要附录；整体评价需覆盖全文，局部分析可聚焦相关章节并说明未覆盖范围。

涉及选题、权威性／影响力或机构与资助背景时，按 [论文评估标准](selection-criteria.md) 展开 identity／assessment：使用论文发表时归属、团队积累和直接资助，以及学术可信度、独立研究影响；不套公司融资模板。仅分析局部方法时不强制补全背景调查。

| 默认字段 id | 章节／问题 |
| --- | --- |
| identity | 标题、作者、机构、日期、论文版本、原始链接、代码与数据是否可得 |
| problem | 研究问题、已有方法的不足、任务定义和适用假设 |
| method | 核心思想、算法、公式、数据流、训练与推理流程；变量和关键步骤的含义 |
| evidence | 数据集与划分、基线、指标、实验设置、主结果、消融、统计可靠性 |
| novelty | 相比最接近工作的增量，作者主张与证据分别是什么 |
| limitations | 失败案例、适用边界、成本、未验证主张与资料缺口 |
| reproducibility | 代码、依赖、模型、数据与预算条件，本次是否实际复现 |
| assessment | 对当前研究目标的价值、可借鉴点及后续验证问题 |

开头给出研究目标和主要判断，关键结论附近引用页码／章节。方法复杂时用流程或伪代码辅助；实验优先表格，保留绝对值、差值、单位与原始条件。

比较多篇论文时，先统一问题、假设和实验口径，再比较方法差异。不同数据划分或预算下的分数分别呈现。将作者实验、外部复现和本次验证分开说明。
