# Survey 论文阅读与报告

survey、review 等以文献综合为主要贡献的论文仍使用 `paper`。单篇对象目录为 `survey-<paper-id>`，如 `research-reports/agent-memory/paper/survey-agent-memory-20261108-120000/report.md`；比较多篇 survey 可用 `compare-survey-<slug>`。目录约定见 [交付规范](../../research/references/delivery-policy.md)。

## 分析维度

| 字段 id | 应回答的问题 |
| --- | --- |
| identity | 实际论文版本、作者、发表信息、原始链接及覆盖截止时间是什么？ |
| scope | 综述针对什么问题，如何定义术语和纳入／排除范围？ |
| selection | 作者如何检索、选择文献，有哪些未披露步骤和选择偏差？ |
| taxonomy | 分类体系的依据是什么，类别是否重叠或遗漏，能否解释代表工作？ |
| coverage | 覆盖哪些路线、工作与时间段，关键遗漏是否影响结论？ |
| synthesis | 作者如何综合证据、比较方法、解释演进与争议，有哪些主张得到支持？ |
| limitations | 时效、覆盖、指标不可比和作者立场如何限制综述判断？ |
| assessment | 对当前问题有什么参考价值，哪些结论需要回查原论文或后续工作？ |

按目标与深度裁剪。作者未说明检索策略时如实记录，不能补写成系统性综述；没有原创实验不构成自动缺口，作者若提出性能比较则仍检查可比口径。研究缺口与未来方向属于作者主张，区分作者意见、被引工作事实和本次评价。

## 交付核对

- 明确该版本的覆盖时间和范围，不把较早综述写成领域最新状态。
- 检查分类依据、代表工作与遗漏，不把论文参考文献列表当作已逐篇阅读全文。
- 对支撑关键判断的被引论文按需要回查，不能把 survey 转述冒充原始实测或独立验证。
- 以论文版本、章节和图表定位主要判断，保留分类与综合结论的适用边界。
- 基于已有调研输出开展主题综合、洞察提炼或路线取舍时，作为独立 analysis 处理，不混入作者原文结论。
