# 技术专题／综述报告结构

围绕一个问题建立分类和综合判断。代表工作服务于分类论证，不按名字堆叠摘要。

| 默认字段 id | 章节／问题 |
| --- | --- |
| scope | 主题、术语、研究目标、时间边界、纳入／排除标准 |
| taxonomy | 问题分解、技术路线分类及分类依据 |
| mechanisms | 各路线如何工作，核心假设、机制与差异 |
| representatives | 代表论文、开源实现、产品与评测及其选择理由 |
| evolution | 时间脉络、关键变化和与旧工作的关系 |
| comparison | 统一问题下的能力、成本、证据与适用边界比较 |
| disputes | 共识、争议、相互矛盾的证据与尚未解决的问题 |
| opportunities | 对研究目标的启示、研究缺口和可验证的后续问题 |

需深查的代表工作可成为 items，并分别使用 paper／open-source／product／benchmark 的类型规范；其他资料仅作为来源。跨类型对象只对共同问题比较，专有实验和实现细节保留各自证据条件。

综述应解释检索与选择边界，避免宣称穷尽全部文献。术语存在多种定义时说明本文用法和原始出处。
